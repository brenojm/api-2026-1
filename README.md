# Monitoria: Desenvolvimento de API - Serratec 🚀

Este repositório contém os exercícios e projetos desenvolvidos durante as sessões de monitoria da disciplina de **Desenvolvimento de API** da Residência em TIC do Serratec.

## 📖 Descrição do Projeto

O objetivo deste repositório é servir como um material de apoio prático para os alunos. Aqui, construímos passo a passo APIs RESTful completas, abordando os conceitos fundamentais do ecossistema Spring. O código é estruturado com foco em boas práticas, como a separação clara de responsabilidades (Arquitetura em Camadas) e o tratamento adequado de regras de negócio.

Durante a monitoria, exploramos:
- Criação de endpoints REST (GET, POST, PUT, PATCH, DELETE).
- Separação em camadas (Controller, Service, Repository, Entity, Exception).
- Persistência de dados utilizando Spring Data JPA.
- Validação de dados de entrada com Spring Validation.
- Tratamento global de exceções (ControllerAdvice).

## 🛠️ Tecnologias Utilizadas

As seguintes tecnologias e ferramentas foram utilizadas neste projeto:

- **Java 17**
- **Spring Boot 3**
  - Spring Web
  - Spring Data JPA
  - Spring Validation
- **Banco de Dados H2** (Em memória)
- **Maven** (Gerenciador de dependências)
- **Postman / Insomnia** (Para testes das requisições)
